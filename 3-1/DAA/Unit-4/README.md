# DAA – Unit 4: Greedy Method and Basic Traversal Techniques

## Overview
This unit focuses on optimization using the **Greedy Method** and fundamental **Traversal and Search Techniques** for binary trees and graphs.

## Topics Covered

### Greedy Method
* **General Method:** Principles of greedy choice property and optimal substructure.
* **Applications:**
  * Job sequencing with deadlines
  * Knapsack problem (Fractional)
  * Minimum cost spanning trees (Prim's and Kruskal's algorithms)
  * Single source shortest path problem (Dijkstra's algorithm)

### Basic Traversal and Search Techniques
* **Techniques for Binary Trees:** Preorder, Inorder, Postorder, and Level-order traversals.
* **Techniques for Graphs:** Breadth-First Search (BFS) and Depth-First Search (DFS).
* **Connectivity:** 
  * Finding connected components
  * Biconnected components and articulation points

## Expected Outcomes
Upon completing this unit, you should be able to:
- Design and analyze greedy algorithms for scheduling and optimization problems.
- Implement graph traversal strategies to solve connectivity and pathfinding problems.
- Evaluate the time and space complexity of greedy solutions.
